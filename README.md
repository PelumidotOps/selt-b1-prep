# SELT B1 Pass Master (UK Health & Care Visa)

A mobile-friendly, high-yield study web app designed to prepare candidates for the **LanguageCert SELT B1 (Achiever) 4-Skills Exam** in 48 hours to secure the minimum 50% pass mark for the UK Health and Care Worker Visa.

## ✨ Features

- **🎙️ Speaking Simulator (Parts 1 - 4):**
  - Text-to-speech audio examiner with British accent prompts.
  - Part 1: Personal info & surname spelling practice.
  - Part 2: Realistic healthcare & daily life roleplays.
  - Part 3: Shared decision-making with key discussion phrases.
  - Part 4: 1.5-minute talk trainer with 30s preparation & 90s speech countdown timer + chimes.
  - In-browser microphone recorder to record and evaluate your own fluency.

- **✍️ Writing Studio (Tasks 1 & 2):**
  - Copy-and-paste 3-paragraph email skeleton (70–100 words).
  - Universal 4-paragraph formal essay/article template (100–120 words).
  - Interactive live sandbox with real-time word counter and B1 connector word highlighter (*However, Although, Furthermore, Therefore...*).

- **🎧 Listening & 📖 Reading Traps:**
  - Interactive "Distractor Trap" audio drills.
  - Keyword and synonym matching tests.

- **⚡ Emergency 48-Hour Plan & Lifesaver Phrases:**
  - Phrases to buy time instead of freezing in silence.
  - Essential healthcare vocabulary (*resident, assistance, routine, compassionate*).
  - Day 1 and Day 2 hour-by-hour revision timetable.

## 🚀 Deployment

### Deploy to Vercel in 1-Click
1. Push this repository to your GitHub account:
   ```bash
   git remote add origin https://github.com/<YOUR-USERNAME>/<REPO-NAME>.git
   git branch -M main
   git push -u origin main
   ```
2. Go to [vercel.com/new](https://vercel.com/new) and import the repository.
3. Click **Deploy**. Vercel will host it automatically as a static site.
